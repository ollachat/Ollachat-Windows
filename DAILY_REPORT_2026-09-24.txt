2. KEY TASKS & ACCOMPLISHMENTS
--------------------------------------------------------------------------------
A. VOICE RECORDER CONTROLLER & COMPOSER INTEGRATION
   - Created `src/renderer/voice-recorder.js` implementing a clean state machine
     (idle -> requesting_permission -> recording -> paused -> stopped -> error).
   - Configured `getUserMedia` with strict `{ audio: true, video: false }` constraints.
   - Handled WebM Opus recording (`audio/webm;codecs=opus`) with duration clamping
     (min 0.5s threshold, max 10m auto-stop).
   - Integrated dynamic recording UI into composer with live duration timer,
     level metering, cancel button, and send action.
   - Added explicit Windows OS / Chromium permission error mapping for
     `NotAllowedError`, `NotFoundError`, and `NotReadableError`.

B. VOICE MESSAGE SENDING PIPELINE
   - Implemented `processAndUploadVoiceNote` to create optimistic message bubbles
     with instant local playback preview.
   - Built resilient multipart upload flow: `initAttachment` -> presigned S3 PUT ->
     `completeAttachment` -> readiness polling via `downloadAttachment`.
   - Formatted backend WebSocket payload adhering strictly to OllaCore contract:
     * kind: "file"
     * body: { text: "Voice message", filename, mime, byte_size, duration, is_voice_note: true }
     * attachment_ids: [attachmentId]

C. ORDINARY AUDIO & MEDIA ATTACHMENT FIXES
   - Fixed MP3 file upload failure in `src/api/mime-validator.js` by expanding
     magic byte validation to detect both ID3 tags (`[0x49, 0x44, 0x33]`) and
     standard MPEG sync frames (`[0xFF, 0xFB/FA/F3/F2/E3]`).
   - Fixed retry payload serialization in `handleRetryMessage` to ensure retry
     dispatches normalize wire `kind` to `'file'`.

D. HISTORICAL VOICE MESSAGES & PERSISTENCE
   - Resolved the infinite "Loading voice message..." bug when reopening rooms
     or restarting the app.
   - Added `attachmentErrors` cache and document-wide placeholder querying to
     transition failed resolutions into actionable retry buttons (`↻ Retry`).
   - Implemented automatic retry on media element playback errors before
     showing retry placeholders.
   - Added audio lifecycle cleanup to pause active voice playback on room switches
     and user logout.
